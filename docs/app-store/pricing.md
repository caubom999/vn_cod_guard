# Pricing Page Draft

## Pricing principle
Start simple. The MVP should be usable on a free tier, then scale by monthly COD order volume.

## Plans

### Free
Price: Free
Limit: 50 COD orders/month
Best for: testing the workflow and small stores.
Includes:
- COD detection
- Order snapshot dashboard
- Email verification in configured mode
- Shopify order tagging
- Basic settings

### Starter
Price: $9/month
Limit: 500 COD orders/month
Best for: small stores using COD daily.
Includes everything in Free, plus:
- Higher monthly order volume
- Reminder/expiry automation
- Risk rules and blacklist tools

### Growth
Price: $19/month
Limit: 2,000 COD orders/month
Best for: growing stores with regular fulfilment teams.
Includes everything in Starter, plus:
- More order volume
- Advanced analytics
- More automation capacity

### Pro
Price: $39/month
Limit: 10,000 COD orders/month
Best for: high-volume COD stores.
Includes everything in Growth, plus:
- Priority support
- Higher automation capacity
- Future channel integrations when available

## Trial
Recommended trial: 7-14 days for paid plans.

## Billing note
For Shopify App Store publication, paid plans must use Shopify Billing. Until public distribution is enabled, paid billing API calls may fail in development.
