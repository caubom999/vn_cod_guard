# Screenshot Plan

Shopify App Store screenshots should show real product value and avoid private data.

## Required screenshot set
1. Overview dashboard
   - Pending, confirmed, cancelled, expired, and risky metrics.
2. Orders list
   - COD orders with status, amount, customer, phone, and risk score masked if needed.
3. Order detail timeline
   - Captured order, verification link created, message queued/sent, customer decision, Shopify tag sync.
4. Settings
   - App enabled, COD payment method names, deadlines, reminder delay, max reminders, custom tags.
5. Message templates
   - Verification and reminder email templates.
6. Blacklist/risk rules
   - Example phone/email/address blacklist and province/order amount rules.
7. Public verification page
   - Customer-facing confirm/cancel page with order name, amount, and shop name.

## Screenshot rules
- Use demo data only.
- Mask emails, phone numbers, addresses, access tokens, and API keys.
- Keep browser UI clean.
- Show Vietnam COD Guard name consistently.
- Do not imply guaranteed fraud prevention.
